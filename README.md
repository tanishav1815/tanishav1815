
# 💫 About Me:
🔭 I’m currently working on: NovaMind, a hackathon prototype that turns chats and live lectures into real‑time summaries and intent (e.g., “buy groceries”, “run tomorrow”), then stores them as structured memory using Supermemory.<br>👯 I’m looking to collaborate on: LLM features for real apps—intent detection, RAG, and task automation inside modern React/Node stacks.<br>🤝 I’m looking for help with: evaluating best practices for memory stores and prompt strategies at scale (latency, cost, observability).<br>🌱 I’m currently learning: Vue.js and Laravel, while deepening AWS data/ML tracks.<br>💬 Ask me about: building Docker + GitHub Actions CI/CD for LLM apps, auth/protected routes, and deploying to AWS.<br>⚡ Fun fact: I like shipping AI features that feel invisible—NovaMind’s “Intent Inbox” is my favorite bit of UX.
